# English

Интерактивный English World 4 на существующем GitHub Pages. Название и старый урок знакомства сохранены; урок доступен по `intro.html`.

## Запуск

Сайт работает без сборки и серверной базы. Для локальной проверки нужен обычный HTTP-сервер (ES-модули не запускаются через `file://`). GitHub Pages публикует корень ветки `main`.

```sh
python -m http.server 8000
node --test tests/data.test.mjs
```

## Структура

- `index.html`, `styles.css` — адаптивный интерфейс.
- `app.js` — 10 разделов, режимы, чтение, запись голоса, письмо, испытание и отчёт.
- `core.js` — проверка ответов, сборка предложений, аудиоплеер, локальный прогресс.
- `games.js` — 18 режимов, включая память, пары и проходимый лабиринт.
- `data/units.js` — архитектура 12 юнитов; наполнен только Unit 4.
- `data/unit4.js`, `audio.js`, `dialogues.js` — проверенный учебный материал и авторские адаптации.
- `data/unit-template.js` — пустая схема следующего юнита.
- `assets/audio` — все 9 исходных MP3 без перекодирования.
- `assets/images` — иллюстрации из предоставленного учебника.
- `docs/UNIT4.md` — карта источников и методический маршрут.

## Результаты и режимы

Прогресс, ошибки, черновики и заметки сохраняются в `localStorage` под отдельным ключом `english-world4-progress-v1`. Это один учебный профиль в одном браузере; между устройствами данные не синхронизируются. Старые заметки урока знакомства сохраняют прежний ключ.

Правильные ответы открываются после попытки либо отдельной кнопкой преподавателя. При переключении в режим ученика все раскрытые ответы удаляются из интерфейса. Режим учителя — настройка показа, а не серверная авторизация. Демонстрационные ответы учителя не начисляют ученику прогресс.

Испытание фиксирует первый ответ на каждый вопрос. Его завершённые попытки сохраняются отдельно от освоения упражнений. Повторные правильные ответы не увеличивают число освоенных заданий сверх размера банка. Ошибки слов сохраняются для повторения.

Запись голоса включается только по нажатию ученика и с разрешения браузера. Запись не отправляется на сервер; её можно скачать. При уходе со страницы микрофон останавливается. Оценки произношения нет. Для произношения отдельных слов используется английский голос браузера; он может быть недоступен. Исходные записи учебника работают независимо от синтеза речи.

## Добавление юнитов

Сначала проверьте страницы и аудио. Создайте данные по `unit-template.js`, сохраните стабильные идентификаторы упражнений и укажите источники. Меняйте статус юнита только после его реализации. Unit 1–3 и 5–12 пока содержат только архитектуру, без вымышленных уроков.

Пользовательские данные не входят в исходный код или Git. Для нескольких учеников, учётных записей и синхронизации потребуется серверное решение.
